## Часть 2. Аудит установленного ПО

Скрипт pc_info.bat собирает сведения о компьютере и сверяет список установленных программ с эталонными списками. Результат сохраняется в pc_report.txt, на экран выводятся сообщения о ходе работы. Скрипт только формирует рекомендации к проверке: решение принимает администратор.

### Категории базового ПО и почему они выбраны

Для типового офисного рабочего места выбраны 5 категорий:

1. Офисный пакет (Microsoft Office, LibreOffice и др.): основа работы с документами и таблицами.
2. Браузер (Chrome, Firefox, Yandex и др.): почти все рабочие сервисы доступны через веб. Microsoft Edge встроен в Windows, поэтому если найден только он, скрипт отмечает это отдельно.
3. Программа для чтения PDF (Adobe Reader, Foxit, Sumatra): большая часть документооборота в PDF.
4. Архиватор (7-Zip, WinRAR и др.): вложения в почте часто приходят в архивах.
5. Антивирус: базовая защита. Кроме списка программ скрипт спрашивает Центр безопасности Windows, потому что Microsoft Defender не значится в списке установленных программ.

### Признаки излишнего ПО

Проверяются 4 группы программ, не относящихся к базовым офисным задачам:

1. Игровые платформы и игры (Steam, Epic Games и т. п.).
2. Торрент-клиенты и файлообменные программы: создают нагрузку на сеть и часто являются источником нежелательного ПО.
3. Мессенджеры для личного общения (Discord, Telegram, WhatsApp и др.). В части организаций это рабочий инструмент, поэтому выводится рекомендация проверить, а не запретить.
4. Инструменты для развлечений и оформления (Wallpaper Engine, проигрыватели и т. п.).

Любая найденная программа выводится как рекомендация к проверке, а не как указание к удалению. Часть программ может быть установлена по согласованию с руководством.

### Как проверялась работоспособность логики

Обе ветви логики проверены на реальном запуске:

1. Ветвь «найдено излишнее ПО». В переменную TEST_EXTRA была временно записана тестовая строка «uTorrent TEST», которая попадает в список программ. Скрипт вывел её в разделе 2 как найденный торрент-клиент (результат в pc_report_test.txt и на screenshot_audit.png). После проверки значение переменной возвращено к пустому.
2. Ветвь «нужной программы нет». Из поиска архиватора временно были убраны реальные названия (7-Zip, WinRAR, WinZip, PeaZip). Скрипт выдал рекомендацию установить архиватор. После проверки названия возвращены.
3. Итоговый запуск без тестовых изменений: pc_report.txt содержит временную метку, раздел проверки базового ПО, раздел проверки излишнего ПО и итог.

### Ограничения решения

- Список программ берётся из ветки реестра HKLM (64-битные и 32-битные установки для всех пользователей). Программы, установленные только для одного пользователя (ветка HKCU), портативные программы и приложения из Microsoft Store не учитываются.
- Поиск идёт по ключевым словам в названии без учёта регистра. Возможны ложные срабатывания (слишком общее слово в названии) и пропуски (программа названа иначе). Эталонные списки нужно периодически обновлять.
- Скрипт не знает роль компьютера: бухгалтерии, разработчику или дизайнеру могут быть нужны другие программы.
- Данные об антивирусе берутся из Центра безопасности Windows. На серверных версиях Windows этот источник недоступен, тогда будет рекомендация проверить антивирус вручную.
- Для получения данных используется PowerShell, поэтому на системах без него часть сведений не будет получена. Скрипт при этом не завершается с ошибкой, а записывает в отчёт, что данные получить не удалось.
- Скрипт даёт рекомендации администратору, а не принимает решения об удалении ПО.
