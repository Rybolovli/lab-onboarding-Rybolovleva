# Деобфускация

Расшифрованная строка: import os; os.system('rm -rf /')

Угроза: команда rm -rf / рекурсивно и принудительно удаляет все файлы
от корня файловой системы. Это приводит к уничтожению ОС, данных и
приложений. exec(b) выполняет эту строку как код.

Методы защиты:
- не использовать exec/eval для данных из недоверенных источников;
- статический анализ кода и поиск base64 + exec (например, bandit);
- запуск программ с минимальными правами и в изолированной среде (контейнер);
- проверка и валидация входных данных, ревью кода.
