# Анализ ассемблерного кода

-4(%rbp) = sum (аккумулятор), начальное значение 0
-8(%rbp) = i (счётчик), начальное значение 1
Условие цикла: cmpl $10 / jle .L3, то есть пока i <= 10
Тело цикла: sum += i; i += 1
Результат (sum) кладётся в %eax.

Эквивалент на Python:

sum_ = 0
i = 1
while i <= 10:
    sum_ += i
    i += 1
# результат: 55 (сумма чисел от 1 до 10)
